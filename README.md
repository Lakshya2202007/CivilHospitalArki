# Civil Hospital Arki - Official Information & Citizen Services Portal

This repository contains the source code for the Civil Hospital Arki portal. It consists of a React.js frontend and a Node.js backend.

## Project Structure

- `/frontend`: React.js application (Public Portal & Admin Panel UI)
- `/backend`: Node.js + Express API

## Development Workflow

1. Each developer works on their designated feature branch (e.g., `aryan-homepage`, `alok-tenders`).
2. Do not commit directly to `main`.
3. Create Pull Requests for code review before merging to `main`.

## Setup Instructions

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
